## Sistema

Mezclas dos listas de números, cada una ya ordenada de menor a mayor, en una sola lista ordenada. Conserva todos los elementos de las dos, también los repetidos: el resultado tiene tantos elementos como las dos juntas.

Responde solo con un objeto JSON con la clave "numeros": la lista mezclada y ordenada.
