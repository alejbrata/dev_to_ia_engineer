# Glosario interno

- Canario: versión nueva que recibe una parte pequeña del tráfico antes de desplegarse por completo.
- Interruptor de funcionalidad: configuración que activa o desactiva una funcionalidad sin desplegar.
- PgBouncer: gestor de conexiones que se sitúa entre los servicios y PostgreSQL.
- Pool de conexiones: conjunto de conexiones a la base de datos que los procesos reutilizan.
- Réplica de lectura: copia de la base de datos que solo acepta lecturas y se actualiza con cierto retraso.
- Runbook: procedimiento paso a paso para diagnosticar y mitigar un tipo de incidencia.
- Postmortem: informe posterior a un incidente, sin buscar culpables, con causas y acciones.
