# Criterios de severidad de las incidencias

Toda incidencia se clasifica con una de cuatro severidades.

- critica: el servicio está caído para todos, o hay pérdida de dinero o de datos.
- alta: una funcionalidad importante falla para muchos usuarios y no hay alternativa.
- media: fallo parcial, intermitente o con alternativa.
- baja: problema menor, cosmético o una consulta.

## Quién decide la severidad

La primera persona que atiende la incidencia propone la severidad. La persona de guardia puede cambiarla. Ante la duda entre dos severidades, se elige la más alta y se revisa después.
